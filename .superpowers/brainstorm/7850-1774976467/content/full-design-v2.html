Zone Definitions

Zone Position Content Color Lifetime
Attention Row 1, Left Unit/city description + reason. No "needs attention" text. E.g., "Fighter [23,15] - Bingo! Refuel?" Gold Persists until unit/city is dealt with
Warning Row 2, Left Blocked movement, combat results, environmental alerts, critical errors. Audible "bonk" on appear. Red Clears on next player action
Command Response Row 3, Left Order confirmations, save/load, waypoints. Quiet — no sound. Light blue (muted) Clears on next player action
Game Status Row 1, Right Round #, PAUSED, exploration %, compact production counts (zeros dropped). Tooltip popup for full detail. Gray / green / red Always visible, updated every round
Inspector Summary Row 2, Right Hover cell info: coordinates, unit type, hits, mode Medium gray Visible while hovering; clears when mouse leaves map
Inspector Detail Row 3, Right Additional hover detail: cargo, fuel, production, dock status Dark gray Visible while hovering; clears when mouse leaves map

Audio

Single "bonk" sound effect via javax.sound.sampled. One bundled .wav file in resources/. Plays once on every warning zone write. No other sounds.

Clearing Rules

Zone Clears when...
AttentionUnit/city is given orders or dismissed
WarningNext player action (any keypress/click)
Command ResponseNext player action (any keypress/click)
Game StatusNever (always visible, updated each round)
InspectorMouse leaves map area
