; Computer Transport Sailing — Pathfinding to Unclaimed or Claimed Land
;
; Loaded transports no longer target cities. They pathfind over sea
; to the nearest unclaimed land on the computer map.
;
; Empty transports pathfind toward the nearest claimed land that is
; outside radius 4, so they can return to a claimed coastline rather
; than immediately switching to loading in open water.
;
; It follows the stored sail-path step by step without
; re-pathfinding until arrival.
;
; On arrival:
;   - Unowned land: unload armies
;   - Sea or computer-owned land: pick new destination
;
; Blocked by enemy: retreat one cell back along the sail-path.
; Empty after unloading: transition to loading.

;===============================================================
; Full transport with armies pathfinds toward unclaimed land.
;===============================================================
GIVEN game map
  t~~~~#
GIVEN computer map
  t~~~~#
GIVEN t has transport-mission loading.
GIVEN t has 6 armies.

WHEN computer transport t is processed.

THEN t has transport-mission sailing.

;===============================================================
; Sailing transport moves two steps along its stored path (speed 2).
;===============================================================
GIVEN game map
  t~~~~~~~~
GIVEN computer map
  t~~......
GIVEN t has transport-mission sailing.
GIVEN t has 6 armies.
GIVEN t has sail-path [[1 0] [2 0] [3 0]].

WHEN computer transport t is processed.

THEN t is at [2 0].

;===============================================================
; Sailing transport arrives at unowned land and unloads.
;===============================================================
GIVEN game map
  ~~t#
GIVEN computer map
  ~~t#
GIVEN t has transport-mission sailing.
GIVEN t has 6 armies.
GIVEN t has sail-path [].

WHEN computer transport t is processed.

THEN t has 5 armies.

;===============================================================
; Sailing transport with armies and exhausted path stays sailing.
;===============================================================
GIVEN game map
  ~~~~~t~~~~~#
GIVEN computer map
  ~~~~~t~~~~~#
GIVEN t has transport-mission sailing.
GIVEN t has 6 armies.
GIVEN t has sail-path [].

WHEN computer transport t is processed.

THEN t has transport-mission sailing.

;===============================================================
; Sailing transport arrives at computer-owned land — picks new destination.
;===============================================================
GIVEN game map
  ~~tX
GIVEN computer map
  ~~tX
GIVEN t has transport-mission sailing.
GIVEN t has 6 armies.
GIVEN t has sail-path [].

WHEN computer transport t is processed.

THEN t has transport-mission sailing.

;===============================================================
; Sailing transport blocked by enemy retreats along path.
;===============================================================
GIVEN game map
  ~~tD~~~~
GIVEN computer map
  ~~tD~...
GIVEN t has transport-mission sailing.
GIVEN t has 6 armies.
GIVEN t has sail-path [[3 0] [4 0]].

WHEN computer transport t is processed.

THEN t is at [1 0].
THEN t has sail-path [[2 0] [3 0] [4 0]].
