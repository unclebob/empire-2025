; Computer threat-response and major invasion behavior.

;===============================================================
; Enemy fighter detection assigns fighter sweep mission.
;===============================================================
GIVEN game map
  f~F
  ~t~
  ~j~
GIVEN computer map
  ...
  ...
  ...

WHEN cell visibility updates for t.

THEN f has threat-mission fighter-sweep.
THEN j has threat-mission fighter-sweep.
THEN f has threat-center [2 0].

;===============================================================
; Fighter sweep mission duration decrements each round.
;===============================================================
GIVEN game map
  f~~
GIVEN f has threat-mission fighter-sweep.
GIVEN f has threat-rounds-left 2.
GIVEN f has threat-center [2 0].

WHEN a new round starts.

THEN f has threat-rounds-left 1.

;===============================================================
; Invasion loading timeout with no armies does not join invasion.
;===============================================================
GIVEN game map
  ~t~
  ###
GIVEN t has transport-mission load-for-invasion.

GIVEN t has invasion-load-since 0.
GIVEN t has 0 armies.

WHEN 6 rounds are complete.

THEN t has transport-mission loading.

;===============================================================

  ~t~
  ###

GIVEN t has major-invasion-target [1 1].

WHEN computer transport t is processed.
