; Transport unloading hold
;
; An unloading transport unloads onto any adjacent empty land (claimed or not),
; then holds position to let armies move away and frees cells for more unloads.

;===============================================================
; Unloading transport unloads immediately onto adjacent land.
;===============================================================
GIVEN game map
  ####
  t~~~
GIVEN computer map
  ####
  t~~~
GIVEN t has transport-mission unloading.
GIVEN t has 2 armies.
GIVEN round-number is 13.

WHEN computer transport t is processed.

THEN t is at [0 1].
THEN t has 0 armies.
THEN t has transport-mission sail-to-load.

;===============================================================
; Unloading transport with only one free cell unloads one army and holds.
;===============================================================
GIVEN game map
  A#
  t~
GIVEN computer map
  A#
  t~
GIVEN t has transport-mission unloading.
GIVEN t has 2 armies.
GIVEN round-number is 13.

WHEN computer transport t is processed.

THEN t is at [0 1].
THEN t has 1 armies.
