; Satellite-specific behavior tests.

;===============================================================
; Satellite needs attention only without target.
;===============================================================
GIVEN game map
  V#
GIVEN V is waiting for input.

THEN the game is waiting for input.

;===============================================================
; Satellite with target does not need attention.
;===============================================================
GIVEN game map
  V###%
GIVEN V's target is %.
GIVEN player units V.

WHEN player items are processed.

THEN the game is not waiting for input.

;===============================================================
; Satellite spawns with turns-remaining 50.
;===============================================================
GIVEN game map
  V#

THEN V has 50 turns remaining.

;===============================================================
; Satellite moves 10 cells per round.
;===============================================================
GIVEN game map
  V~~~~~~~~~=
GIVEN V is waiting for input.

WHEN the player presses D.

THEN at next round V will be at =.

;===============================================================
; Satellite can move over land.
;===============================================================
GIVEN game map
  V#########=
GIVEN V is waiting for input.

WHEN the player presses D.

THEN at next round V will be at =.

;===============================================================
; Satellite skips over a city.
;===============================================================
GIVEN game map
  V####O#####%
GIVEN V is waiting for input.

WHEN the player presses D.

THEN at next round V will be at %.

;===============================================================
; Satellite skips over a unit.
;===============================================================
GIVEN game map
  V####A#####%
GIVEN V is waiting for input.

WHEN the player presses D.

THEN at next round V will be at %.

;===============================================================
; Satellite skips over an enemy unit and does not attack it.
;===============================================================
GIVEN game map
  V####a#####%
GIVEN V is waiting for input.

WHEN the player presses D.

THEN at next round V will be at %.
THEN there is an a at [5 0].
THEN no unit at [0 0].

;===============================================================
; Armies cannot attack satellites.
;===============================================================
GIVEN game map
  Av
GIVEN A is waiting for input.

WHEN the player presses d and wins the battle.

THEN there is an A at [0 0].
THEN there is a v at [1 0].

;===============================================================
; Computer satellite skips over a player city.
;===============================================================
GIVEN game map
  v####O#####%
GIVEN v has direction [1 0].

WHEN a new round starts.

THEN v is at [11 0].
