; Computer Transport Loading and Sailing
;
; Computer transports use a mission-based state machine:
;   - idle: newly created, no mission assigned yet
;   - hold-sail-to-load: wait before replanning a load mission
;   - loading: hold at a planned coastal pickup cell while armies board
;   - sailing: compatibility alias for normal transport movement
;   - unloading: drop armies onto adjacent land at unexplored coast
;
; Loading details:
;   - The transport only enters loading with a planned manifest.
;   - Loading transports hold position and wait for recruited armies.
;   - If no valid loading plan exists, the transport enters hold-sail-to-load
;     and replans later.
;
; Sailing details:
;   - The transport picks a random heading and sails in that direction.
;   - On hitting unexplored coast, it switches to unloading.
;   - On hitting map borders or explored coast, the heading reflects.
;
; Unloading details:
;   - Armies are dropped onto adjacent empty land cells.
;   - When fully emptied, the transport returns to loading.

;===============================================================
; Idle transport enters hold-sail-to-load when no valid load plan exists.
;===============================================================

  t~~~

  ~~~~
  ~~~X

WHEN a new round starts.

THEN t has transport-mission hold-sail-to-load.
THEN t has sail-path [].

;===============================================================

  ###~
