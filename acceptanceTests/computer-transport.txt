; Computer Transport Loading and Sailing
;
; Computer transports use a mission-based state machine:
;   - idle: newly created, no mission assigned yet
;   - loading: coastal crawl along shoreline, auto-load adjacent armies
;   - sailing: heading-based movement with reflection off borders/explored coasts
;   - unloading: drop armies onto adjacent land at unexplored coast
;
; Loading details:
;   - The transport follows the coastline (coastal crawl) while
;     auto-loading adjacent computer armies.
;   - When not near land, the transport explores toward the nearest
;     unexplored coastline.
;   - When the transport reaches 6 armies, it transitions to sailing.
;
; Sailing details:
;   - The transport picks a random heading and sails in that direction.
;   - On hitting unexplored coast, it switches to unloading.
;   - On hitting map borders or explored coast, the heading reflects.
;
; Unloading details:
;   - Armies are dropped onto adjacent empty land cells.
;   - When fully emptied, the transport returns to loading.

;===============================================================
; Idle transport transitions to loading on first processing.
;===============================================================
GIVEN game map
  t~~

WHEN a new round starts.

THEN t has transport-mission loading.

;===============================================================
; Loading transport coastal-crawls along shoreline.
;===============================================================
GIVEN game map
  ~t
  ##
GIVEN t has transport-mission loading.

WHEN a new round starts.

THEN t is at [0 0].

;===============================================================
; Loading transport stays put in open sea with no land.
;===============================================================
GIVEN game map
  t~~~
GIVEN computer map
  ....
GIVEN t has transport-mission loading.

WHEN a new round starts.

THEN t is at [0 0].

;===============================================================
; Full transport switches to sailing.
;===============================================================
GIVEN game map
  ~~~
  ~t~
  ~~~
GIVEN t has transport-mission loading.
GIVEN t has 6 armies.

WHEN a new round starts.

THEN t has transport-mission sailing.

;===============================================================
; Sailing transport unloads at unexplored coast.
;===============================================================
GIVEN game map
  ~t~#
GIVEN t has transport-mission sailing.
GIVEN t has 6 armies.
GIVEN t has sail-path [[2 0]].

WHEN a new round starts.

THEN t is at [2 0].
THEN t has transport-mission sailing.
THEN t has 5 armies.
