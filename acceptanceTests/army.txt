; Army-specific behavior tests.
; Basic movement already covered in unit-movement.txt.

;===============================================================
; Army put to sentry mode.
;===============================================================
GIVEN game map
  A#
GIVEN A is waiting for input.

WHEN the player presses s.

THEN A has mode sentry.

;===============================================================
; Army set to explore mode.
;===============================================================
GIVEN game map
  A#
GIVEN A is waiting for input.

WHEN the player presses l.

THEN A has mode explore.

;===============================================================
; Army wakes near hostile city with reason.
;===============================================================
GIVEN game map
  A#+
A's target is +

WHEN a new round starts and A is waiting for input.

THEN the attention message contains :army-found-city.

;===============================================================
; Army conquers free city.
;===============================================================
GIVEN game map
  A+
GIVEN A is waiting for input.

WHEN the player presses d and wins the battle.

THEN cell [1 0] is a player city.

;===============================================================
; Army skips round with space.
;===============================================================
GIVEN game map
  A#
GIVEN A is waiting for input.

WHEN the player presses space.

THEN the game is not waiting for input.

;===============================================================
; Army blocked by friendly city.
;===============================================================
GIVEN game map
  AO
GIVEN A is waiting for input.

WHEN the player presses d.

THEN at the next step the attention message contains :cant-move-into-city.

;===============================================================
; Computer map updated when player conquers computer city.
;===============================================================
GIVEN game map
  AX
GIVEN computer map
  .X
GIVEN A is waiting for input.

WHEN the player presses d and wins the battle.

THEN cell [1 0] is a player city.
THEN on the computer-map cell [1 0] is a player city.

;===============================================================
; Computer sentry army on coast stays put.
;===============================================================
GIVEN game map
  ~a~+
GIVEN a has mode sentry.
GIVEN a belongs to country 1.
GIVEN territory around a belongs to country 1.

WHEN a new round starts.

THEN a remains unmoved.

;===============================================================
; Random-explore army goes sentry on coast.
;===============================================================
GIVEN game map
  ~a##
GIVEN a has mode random-explore.
GIVEN a belongs to country 1.
GIVEN territory around a belongs to country 1.
GIVEN a has random-explore-direction [1 0].

WHEN a new round starts.

THEN a has mode sentry.

;===============================================================
; Random-explore army moves when inland.
;===============================================================
GIVEN game map
  ####
  #a##
  ####
GIVEN a has mode random-explore.
GIVEN a belongs to country 1.
GIVEN territory around a belongs to country 1.
GIVEN a has random-explore-direction [1 0].

WHEN a new round starts.

THEN a is at [2 1].

;===============================================================
; Sentry army wakes for attack assignment.
;===============================================================
GIVEN game map
  ~a~~+
GIVEN a has mode sentry.
GIVEN a belongs to country 1.
GIVEN territory around a belongs to country 1.
GIVEN + is visible to computer.

WHEN a new round starts.

THEN a has attack-target nil.

;===============================================================
; Coast-walk terminates at map boundary.
;===============================================================
GIVEN game map
  a~
GIVEN a has mode coast-walk.
GIVEN a has coast-direction clockwise.
GIVEN a has coast-start [0 0].
GIVEN a belongs to country 1.

WHEN a new round starts.

THEN a has mode sentry.
