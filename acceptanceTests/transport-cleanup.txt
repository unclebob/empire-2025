; Transport cleanup
;
; Loading transports should not crawl, and loaded transports should not enter
; sail-to-unload without a real unload path.

;===============================================================
; Full loading transport without an unload path falls back to hold-sail-to-load.
;===============================================================

  ~~~t~~~
GIVEN computer map
  ~~~t~~~
GIVEN t has transport-mission loading.
GIVEN t has army-count 6.

WHEN computer transport t is processed.

THEN t is at [3 0].
THEN t has transport-mission hold-sail-to-load.
