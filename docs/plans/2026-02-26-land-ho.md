# Land-Ho Target List Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** When computer units discover free cities, catalog them into a target list that transports use to launch targeted invasions.

**Architecture:** New `land-ho-targets` atom (ordered list, FIFO queue) of free city positions. Discovery happens in `update-cell-visibility` when computer-map reveals a free city. At round start, the first target is paired with the nearest qualifying transport, which enters a new `:invading` mission mode. Invading transports follow a precomputed BFS sea path, then coast-crawl-unload at the destination.

**Tech Stack:** Clojure, Speclj (TDD), atoms for state

(defn bfs-to-land-ho-target
  "BFS over known sea cells on computer-map from start toward target-city.
   Returns a path (excluding start) of sea cells ending at a sea cell
   adjacent to target-city. Returns nil if no sea path exists.
   Returns [] if start is already adjacent to target-city."
  [start target-city computer-map]
  (let [adjacent-to-target? (fn [pos]
                              (some #(= target-city %)
                                    (map-utils/get-neighbors pos)))
        passable-sea? (fn [pos]
                        (let [cell (get-in computer-map pos)]
                          (and cell (= :sea (:type cell)))))]
    (if (adjacent-to-target? start)
      []
      (when (passable-sea? start)
        (loop [queue (conj clojure.lang.PersistentQueue/EMPTY start)
               visited #{start}
               came-from {}]
          (when (seq queue)
            (let [current (peek queue)]
              (if (adjacent-to-target? current)
                (vec (rest (map-utils/reconstruct-path came-from start current)))
                (let [neighbors (bfs-sea-neighbors current visited passable-sea?)
                      new-came-from (reduce #(assoc %1 %2 current) came-from neighbors)]
                  (recur (reduce conj (pop queue) neighbors)
                         (into visited neighbors)
                         new-came-from))))))))))
```

(ns empire.computer.land-ho
  (:require [empire.atoms :as atoms]
            [empire.movement.pathfinding-bfs :as pathfinding-bfs]
            [empire.movement.map-utils :as map-utils]))

(defn- find-sailing-transports
  "Returns list of [pos transport] for computer transports in sailing mode
   with 4+ armies."
  []
  (let [game-map @atoms/game-map
        height (count game-map)
        width (count (first game-map))]
    (for [r (range height)
          c (range width)
          :let [cell (get-in game-map [r c])
                unit (:contents cell)]
          :when (and unit
                     (= :transport (:type unit))
                     (= :computer (:owner unit))
                     (= :sailing (:transport-mission unit))
                     (>= (:army-count unit 0) 4))]
      [[r c] unit])))

(defn- nearest-transport
  "Returns [pos transport] of the transport nearest to target, or nil."
  [transports target]
  (when (seq transports)
    (apply min-key (fn [[pos _]] (map-utils/distance pos target)) transports)))

(defn assign-land-ho-invasion
  "At round start, try to assign the first land-ho target to the nearest
   qualifying transport. One assignment per round."
  []
  (when-let [targets (seq @atoms/land-ho-targets)]
    (let [target (first targets)
          transports (find-sailing-transports)]
      (if (empty? transports)
        nil ;; No qualifying transports — leave target at front
        (let [[tpos _] (nearest-transport transports target)
              path (pathfinding-bfs/bfs-to-land-ho-target
                     tpos target @atoms/computer-map)]
          (if path
            (do
              ;; Assign transport to invading mode
              (swap! atoms/game-map assoc-in
                     (conj tpos :contents :transport-mission) :invading)
              (swap! atoms/game-map assoc-in
                     (conj tpos :contents :invasion-target) target)
              (swap! atoms/game-map assoc-in
                     (conj tpos :contents :invasion-path) (vec path))
              ;; Remove target from queue
              (swap! atoms/land-ho-targets #(vec (rest %))))
            ;; BFS failed — move target to end of queue
            (swap! atoms/land-ho-targets
                   #(conj (vec (rest %)) target))))))))
```

(defn- process-invading-mission
  "Follow precomputed invasion path. Steps up to 2 cells per round.
   When path exhausted, transition to unloading with coast-crawl."
  [pos]
  (let [transport (get-in @atoms/game-map (conj pos :contents))
        path (:invasion-path transport)]
    (if (empty? path)
      (set-transport-mission pos :unloading)
      (let [step1 (first path)
            remaining1 (vec (rest path))]
        (if (core/move-unit-to pos step1)
          (do
            (visibility/update-cell-visibility pos :computer)
            (visibility/update-cell-visibility step1 :computer)
            (if (empty? remaining1)
              (do (swap! atoms/game-map update-in (conj step1 :contents) dissoc :invasion-path)
                  (set-transport-mission step1 :unloading))
              (let [step2 (first remaining1)
                    remaining2 (vec (rest remaining1))]
                (if (core/move-unit-to step1 step2)
                  (do
                    (visibility/update-cell-visibility step1 :computer)
                    (visibility/update-cell-visibility step2 :computer)
                    (if (empty? remaining2)
                      (do (swap! atoms/game-map update-in (conj step2 :contents) dissoc :invasion-path)
                          (set-transport-mission step2 :unloading))

                         (conj step1 :contents :invasion-path) remaining1)))))
          ;; Blocked — keep path for retry next round
          nil)))))
